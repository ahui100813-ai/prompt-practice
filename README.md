# 提示词练习教练 · Prompt Practice

把“知道提示词应该怎么写”变成“自己能写出来”。这是一个中文 Agent Skill，让 AI 出题、点评你写的提示词，带你修改、验证并复盘。

适合想练习写作、研究、设计生图、编程与 Agent 协作的人。默认一轮约 10 分钟，一次只练一题；你也可以带自己的真实任务来练。

## 它怎么带你练

```text
出题 → 你写第一版 → 五维点评 → 你改一版 → 检查实际输出 → 复盘
```

- **四个方向、12 道分级题**：每个方向各有初级、中级、高级题。
- **固定五维 20 分制**：目标、背景与资料、约束、输出形式、验收与验证。
- **每轮只改 1—2 个重点**：先自己练；想看完整示范时可以直接提出。
- **提示词与实际结果分别评价**：未生成图片、未运行代码、未核验来源时，明确标为未实测。
- **可复制的复盘记录**：不自动保存个人作业，也不承诺跨聊天永久记忆。

skill 本身不需要额外 API Key、Python 或插件。它仍需要支持 Agent Skills 的 AI 客户端及该客户端的模型访问；真正联网、生图或运行代码时，需要对应工具，本 skill 不附带这些服务。

在 Codex 中发送：


这是 skill 文件夹的链接，不是整个仓库根目录。安装后在 skill 列表查找“提示词练习教练”；若没有显示，重启 Codex。

也可下载或克隆仓库，将 `skills/prompt-practice` 整个文件夹复制到当前项目的 `.agents/skills/`，或个人目录 `~/.agents/skills/`。保留其中的 `references` 和 `agents` 文件夹。Codex 的发现位置和安装机制见 [官方 skill 文档](https://developers.openai.com/codex/skills/)。

本项目按 [Agent Skills 格式](https://agentskills.io/specification) 编写。其他支持该格式的客户端请按其自身安装说明导入；本仓库不声称已经测试所有客户端。

## 开始练习

安装后复制一句即可：

```text
使用 $prompt-practice。我是新手，每天 10 分钟，四个方向轮换。
今天先出一道题，等我写完再点评。
```

其他用法：

```text
使用 $prompt-practice，今天练产品设计生图提示词，中级，先不生成图片。
```

```text
使用 $prompt-practice。我写了一条让 Agent 修 bug 的提示词，
请只评价表达和任务范围，不要执行。提示词如下：……
```

```text
使用 $prompt-practice，先给我一份参考提示词并解释取舍，这次不做练习。
```

## 一次练习是什么样

**教练出题**：为校园二手书交换会写班级微信群文案。材料包括本周六 14:00—17:00、图书馆一楼大厅、免费、每人带一本闲置书。验收条件是 120 字以内、事实完整、不编造福利。本轮练补齐上下文。

**你写**：

> 帮我写校园二手书交换会宣传文案，要有吸引力。

**教练反馈**：按五维说明已表达和缺失的内容。这轮先补活动事实或明确引用题干，再明确渠道、长度与事实边界；邀请你提交下一版，不急着替你写完。

**你修改**：

> 请根据上面的活动资料，写一段发在班级微信群的宣传文案。面向大学生，语气亲切简洁，120 字以内。包含时间、地点、免费和带一本闲置书的规则，不要添加未提供的福利。输出文案后单独检查以上条件；有缺失资料就先指出，不编造。

**教练验证**：先检查提示词，再看你提供或在对话中生成的实际文案。若文案出现“现场送礼品”，即使提示词较完整，也应判定该项未通过。没有实际文案时，只给静态点评和待验证项。

这是使用方式示例，不是对任何模型的实际效果保证。评分是帮助学习的主观反馈；同一题目用固定尺度有助于复盘，跨任务的分数不能直接当作能力排名。

## 修改与验证

改 skill 时，用 [行为场景](tests/scenarios.md) 在独立对话中复测，保留实际回复并按判据检查。格式验证不能代替行为验证；人工或 Agent 模拟通过也不等于所有模型和真实任务都通过。当前验证记录见 [RESULTS.md](tests/RESULTS.md)。

贡献可以聚焦于新练习题、评分说明和实际失败案例。请提供任务材料、提示词、可复现的问题与预期行为，移除私人信息。
