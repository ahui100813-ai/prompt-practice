# AI 动画电影分镜 Skill V3.0

将《放门口》式电影分镜写法、AI视频的起止状态控制、固定场景布局与连续性检查融合成一套**跨项目通用**的 Skill。

## 文件结构

- `SKILL.md`：技能触发条件、执行流程、优先级与最终输出标准。
- `references/storyboard-template.md`：复制即用的正式分镜空白模板。
- `references/continuity-audit.md`：跨镜/跨组连续性自检与问题优先级。
- `references/example-group.md`：简短示范一组镜头如何管理状态与反打。
- `templates/state-ledger.csv`：可用表格软件记录每组/每镜的状态。

## 怎么使用

1. 在支持 `SKILL.md` 的 AI 助手或 Agent 环境中，将整个 `ai-animation-storyboard-v3` 文件夹放入它支持的技能目录，按该平台的方式启用。不同平台的路径与导入方式可能不同。
2. 给助手提供剧本、大纲、角色图、场景图和已确认的资产。可以说：“使用 ai-animation-storyboard-v3 把这段剧本整理为正式分镜并检查连续性。”
3. 如果只想先审查、不想改剧本，请明确说“先分析问题，不改原稿”。
4. 如果作品要求逐张确认场景，请明确说“每张场景确认后再继续”。

**注意**：这是本地可下载的技能文件包，不代表已经自动安装到你的 ChatGPT 或其他平台；需要你在支持技能的环境中导入或放置文件。
