# AI 动画电影分镜与视频生成 Skill V3.0

## 目标

把用户提供的故事材料组织成**可执行、可剪辑、可复用**的电影化动画分镜，同时避免生成式视频常见的角色变形、场景镜像、道具瞬移、动作断裂与剪辑跳切。

**三项并列目标**：
1. **电影表达**：准确传达故事、情绪、动作节奏、摄影机机位和声音。
2. **可生成性**：将复杂动作拆成模型能够完成的连贯片段；不把无关动作硬塞进一个镜头。
3. **连续性**：相邻镜头及相邻生成段落的世界坐标、人物状态、道具状态和光照一致。

## 核心约束（优先级由高到低）

1. 用户已确认的**剧本、角色外观、场景母版、道具资产及特殊要求**高于所有默认模板；不能因格式规范擅自改写故事。
2. **全片视觉总控只在完整主稿开头写一次**；每组的情绪、空间、资产、起始与结束状态各写一次，不要每镜重复完整角色设定。若用户明确要求独立可粘贴的单段生成词，则复制该段必需的最小一致性锚点，不是整篇总控。
3. **默认不标注镜头秒数**。用户提供总片长、原剧本时间码时，应保留其信息，但默认放在单独的节奏/时长规划，不自动把秒数强行写入逐镜文本。明确要求逐镜秒数时才标注。
4. **上一段尾帧锁定人物和道具的空间位置、姿势、朝向、状态与光影；绝不默认锁定下一镜的景别、机位、焦段、反打或构图。**
5. **场景空间坐标**不等于**屏幕左右**。先锁定门、窗、桌、地形和行进通道，再根据摄影机朝向决定屏幕位置；允许反打引起屏幕左右变化，禁止真实空间镜像。
6. **物体状态不会自行重置**：门、灯、屏幕、衣物、纸张破损、手持道具、液体、碎片等必须有可解释的状态变化。时间跳跃可用转场或场次切换明确说明。
7. **动作的起点—执行—落点—下一动作**必须完整；动作之间建立因果。对复杂生成段落记录本段结束状态，确保下一段可接续。
8. **声音、运镜、色彩由具体项目决定**。不得跨项目套用“无 BGM”“纯冷色”“禁甩镜”“一定 3D”等非通用限制。
9. 提示词**不应凭空假装见过**参考图、首帧、尾帧或素材；没有获得具体图像时只按文字描述，标出待确认的外观/位置。用户要求基于文件检查时先查文件。
10. 完成后**主动自检并修复确定的穿帮**；无法确认的疑点只标记，不虚构解决方案。用户要求保留原文时，问题与建议单列而不偷偷改写。

## 启用场景与响应路径

- **只有剧本/大纲**：先提炼故事节拍、角色、空间、关键道具与场次；指出影响分镜生成的实质性矛盾，确认/标记未定资产后再写逐镜。
- **已有分镜，需要整理为统一格式**：保留其镜头事件、台词、人物和顺序；将内容填入本 Skill 的分组母版。
- **已有首帧/尾帧、视频段或参考图**：先读实际素材，锁定可见空间和动作状态，再写后续；不得把上一帧的构图误当成唯一拍法。
- **只要求特定镜头或组**：仅输出所需范围及必要上下文，不擅自扩展整部影片。
- **用户要求场景/角色逐张审批**：每次只推进已授权的场景，标记“候选/已确认”，不得把未经确认的生成图写成固定母版。
- **用户要求“纯模板/Skill”**：输出跨项目通用规则，拒绝将某一部动画的角色、美术与对白硬编码进去。

## 制作流程

### A. 整理事实与创作约束

1. 提取项目片名、类型、画幅、目标时长（若有）、故事场次与必保留台词。
2. 提取全片统一的美术、角色、声音、镜头运动、禁止项。只以用户提供或明确确认的信息为准。
3. 建立资产清单：`人物ID / 场景ID / 道具ID / 参考图 / 已确认状态 / 关键识别点`。
4. 建立空间锚点：固定物体位置、出入口、世界朝向、角色可达路径和大小比例。
5. 对不明内容使用【待确认】；能做中性合理编排的镜头可继续推进，不因次要缺失阻塞全稿。

### B. 划分镜头组

按**地点连续、事件连续、情绪单元或视频生成容量**分组，而非机械按镜头数量分组。每组写：
- 【本组情绪总控】剧情目标、情绪起点/变化/终点、表演节奏。
- 【本组场景空间与画面布局规则】世界坐标、固定物体、活动通道、必要的背景连续资产及摄影机空间限制。
- 【本组资产调用】该组出现的人物、场景、道具及其参考编号，集中一次。
- 【本组起始状态】真实承接前一段尾帧，不允许角色或道具重置。
- 【逐镜】镜头名称、焦段、景别、机位、运镜、站位、动作、对白、光影、现场声、结束状态、剪辑衔接。
- 【本组结束状态】锁定可供下一组使用的最终状态。
- 【本组连续性自检】列出已验证项目与待解决疑点。

### C. 写每个镜头

使用`镜头01｜名称`、`镜头02｜名称`连续编号。镜头必须回答：

- **看什么**：镜头表达目的、主要人物/物体、前中后景。
- **从哪里看**：焦段 mm（有必要时）、景别、摄影机高度/方向/与角色关系。
- **怎么拍**：固定、推、拉、移、跟拍、升降、环绕或变焦/焦点转移；只有经过项目允许时使用相应手法。
- **怎么动**：人物位置、手/脚/眼神/重心、动作起点和次序、与道具交互及落点。
- **什么声音**：对应对白、旁白、环境音、拟音及音乐策略；声音必须和项目总控相符。
- **停在哪里**：画面结束时的角色姿态、接触关系、道具及环境状态。
- **如何接下一镜**：动作匹配、视线匹配、方向一致、反打、遮挡、声音桥接或明确省略；避免连续两个几乎同构图镜头带来的不必要跳切。

**镜头切换优先原则**：先保证叙事清楚，再兼顾画面变化。镜头可以从中景切到近景、反打、俯仰视角，不为“尾帧对齐”强迫保持原机位。

### D. 生成容量与时长

- 默认**不写逐镜秒数**；保留用户明确提供的时间表，且不随意重新估时。
- AI 视频单次生成难以完成过多不同机位/对象交互时，把原镜头拆为可生成片段，**不得变更剧本镜头逻辑**。
- 连续动作写明`上一段尾帧状态 → 本段动作 → 本段结束状态`，此三段可以放在分镜组首尾，而不必每一行重复。
- 一段生成词中避免互相矛盾的运镜命令。长时间一镜到底需要检查运动路径是否可达、是否会穿墙、穿窗或穿人。

### E. 自检与交付

依据 [references/continuity-audit.md](references/continuity-audit.md) 检查：
1. **剧情逻辑**：因果、人物知情状态、时间变化。
2. **物理与尺度**：身高/家具尺寸、落点、重力、道具可抓取性和运动线路。
3. **空间**：建筑结构、左右轴线、站位、路径、机位及反打。
4. **资产**：服装、发型、道具唯一性、损坏/开关/持有状态、颜色。
5. **声音光影**：光源与昼夜、灯/屏幕是否开启、音效对白连续性。
6. **剪辑**：运动方向、景别与机位变化、镜头衔接、重复动作、时间省略是否交代。

**错误处理**：确定错误立即修正，并在末尾用简短的【本组连续性自检】报告修正点；若涉及用户明确锁定的剧情，不擅自修改，标记【需用户决定】并给出最小修正建议。

## 输出格式契约

**完整项目的输出顺序**：

```text
# 《片名》｜电影分镜与AI视频生成稿
【全片视觉总控】（全篇一次）

## 第一组｜组名
【本组情绪总控】
【本组场景空间与画面布局规则】
【本组资产调用】
【本组起始状态】
【逐镜】
镜头01｜名称
  焦段、景别、机位、运镜
  人物站位与画面
  动作过程
  对白／旁白（需要时）
  光影
  现场声
  镜头结束状态
  剪辑衔接
镜头02｜...
【本组结束状态】
【本组连续性自检】

## 第二组｜...
...
```

在完整剧本中**不在每组重复【全片视觉总控】**，也**不在每镜重复【本组资产调用】**。镜头中的某项确实不存在（如没有对白），可省略空字段；**涉及状态变化的镜头不能省略“镜头结束状态”**。

查看一个**不绑定具体动画风格**的短组示范：[references/example-group.md](references/example-group.md)。
如需记录多次生成迭代，使用：[templates/state-ledger.csv](templates/state-ledger.csv)。

## 交付质量标尺

- **A｜可制作**：空间、资产、动作、机位、声音、尾帧全部清晰，无已知连续性冲突。
- **B｜需校对**：有不影响主要剧情的未确认细节；明确标注但不能声称已定稿。
- **C｜不可直接生成**：存在人物瞬移、相互矛盾的机位或道具、严重的物理断裂；先修复再交付。

**成功标准**：读者无需自行补猜关键站位和道具变化，便能按组调用资产、生成分镜视频，并在剪辑中连贯衔接。
