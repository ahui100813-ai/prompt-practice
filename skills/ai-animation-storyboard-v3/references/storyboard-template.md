# AI动画电影分镜与视频生成｜通用填空母版 V3.0

> 用法：复制后替换方括号，整部影片写一次全片总控；以下“本组”模块每组写一次。默认不在逐镜写秒数，项目明确要求时例外。

# 《【项目片名】》｜正式分镜与AI视频提示词

## 【全片视觉总控】

**影片类型／题材：**【2D / 3D / 定格 / 纸艺 / 其他；剧情类型】

**整体美术风格：**【人物造型、场景绘制方式、材质、纹理、绘画语言、画面完成度、参考作品中要借鉴的具体视觉特征】

**角色表现：**【比例、面部结构、表情系统、动作节奏、夸张程度】

**场景与质感：**【建筑/环境材质、生活细节、尺度规则、气氛】

**色彩规则：**【主/辅/强调色、不同剧情阶段的色彩限制】

**光影规则：**【时间、光源、光向、阴影、体积光/反射/景深】

**摄影机规则：**【允许的机位运动和禁止的运动；运动服务叙事】

**声音规则：**【对白、旁白、环境音、拟音、音乐是否允许以及具体限制】

**画面技术规范：**【画幅、字幕/文字/标志/水印限制、分辨率/帧率如有】

**资产统一：**【全片不变的角色身份特征、道具与场景约束】

## 【独立生成片段补充规范（仅在需要时使用）】

对某一镜需拆成数段生成时，单段提示词前面放最少必要资产锚点，再明确：

**上一段尾帧状态：**【人、道具、空间、灯光】

**本段唯一主要动作链：**【开始动作→过程→结束动作】

**本段结束状态：**【为下段起始提供明确状态】

**可重新设计的摄影机：**【新镜景别、焦段、机位、反打；遵守场景真实布局】

### 时间信息处理
- 默认不写逐镜秒数。
- 若已有总时长/时间表，另列**节奏规划表**保存，不以此强制限制每镜实际表演。
- 用户明确要求时间码时，再增加 `镜头01｜起止时间`。
